# fast kali commands


<h1 align="center">Kali Auto Updater</h1>
<p align="center"> Quick Disclaimer </p>


This script manages system packages and APT repositories on Kali Linux.

Before running it:
 - Make sure you are using Kali Linux.
 - Run the script with sudo.
 - Keep a stable internet connection during updates.
 - Avoid interrupting package installation or upgrade processes.
 - The script uses standard Kali/Debian package management commands and is intended to simplify routine system maintenance.
 - The script will install gum automatically. 
 - --> Root privileges are required. Run the script using `sudo`. <--

  <h1 align="center">Direct Downloading</h1>

 - If you download the kali-updater file directly from GitHub, make it executable before running it

 - chmod +x kali-updater
 - sudo ./kali-updater
 <p align="center">if the files was Downloaded to your Downloads folder: </p>
 
 - cd ~/Downloads
 
 - chmod +x kali-updater
 
 - sudo ./kali-updater

  <h1 align="center">the script requires sudo because it manages system packages, APT repositories, and package configuration</h1>
